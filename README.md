# AI Coding Agent

## Overview

AI Coding Agent is a Python-based tool that automates code modification using Google's Gemini API.

The agent:
- Explores a repository
- Identifies relevant files
- Generates an execution plan
- Modifies source code
- Creates backup files
- Validates generated code
- Generates a summary report

---

## Features

- Repository Explorer
- AI Execution Planner
- AI Code Modifier
- Automatic Backup
- Code Validation
- Summary Generation
- Logging
